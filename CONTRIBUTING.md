# Contributing

Thank you for helping. The rules in [AGENTS.md](AGENTS.md) apply to
everyone, people and agents alike.

- To suggest an idea or report a bug, open an issue on GitHub. It is
  copied to our main work list and answered there.
- A pull request on GitHub is copied into our main repository. Once a
  person approves it and every check passes, an agent applies it on
  `main`. How this works is in
  [AGENTS.md section 9.2](AGENTS.md#92-outside-contributions).
- Sign off each commit with `git commit -s`. The commit message form is
  in [AGENTS.md section 9](AGENTS.md#9-git-and-github).
