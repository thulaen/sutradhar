# Edge-case index

Owner: feature specification authors and reviewers.
Status: requirements index; executable cases and fixtures are not yet implemented.

The full requested case inventory is retained in
[Q148](requirements/sources/interview-121-150.md#q148). Read later decisions in the
[override ledger](requirements/overrides.md) before turning a historical case
into an active test. Q155 defines the relevant fixture approach; R053 and R058
in [current decisions](requirements/current-decisions.md) record the current rule.

Each approved feature specification must identify its applicable source cases,
expected result, synthetic fixture and acceptance evidence. Preserve the starred
release-blocking cases. Do not count renamed cases, empty placeholders or copied
variants towards the requested meaningful case count.

Real corpus execution belongs on the authorised private validation host. Public
fixtures, screenshots and examples must be synthetic and privacy-reviewed.
The [acceptance ledger](requirements/acceptance-ledger.md) remains open until the
implemented checks and their failure behaviour have been demonstrated.
