# Phase 6, first feature range

The [feature register](../specs/feature-register.md) assigns owners for
features 1 to 112. [Features](../specs/features.md#range-1-features-1-to-112)
gives their source descriptions. The
[implementation catalogue](implementation-catalogue.md) gives the
phase and the test catalogue gives the evidence format.

The owner column is a routing reference. A register basis describes
how ownership was assigned. It proves neither a behaviour nor feature
readiness. Before a build task is created, the owning spec needs the
full [spec 0076 record](../specs/0076-specification-completeness.md) and
the approved scope entry. Use one design owner per feature. Keep any
shared check bound to the requirements of the feature that uses it.

The roadmap orders work within the range as insight, review, draft
and public-page behaviour. A title or a source description alone
cannot settle the lane. An observation that also writes to a page
needs the public-page contract and footprint evidence.
