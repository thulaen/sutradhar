# Interview source index

Status: captured source history; not implementation evidence.

All 209 numbered questions and answers are retained below. Read [current decisions](../current-decisions.md) and [changes to earlier decisions](../overrides.md) before applying an old answer. Selected option descriptions give meaning to short answers such as 'option 1'. Unselected options are historical context, not requirements.

Private identifying text is replaced by explicit redaction markers. These source files preserve wording and spelling; editorial documents use British spelling. No private transcript path, session identifier, forum name, licensed archive name, disk identifier or credentials belong here.

Line endings use LF and terminal spaces in prose are removed for consistent
source formatting. This does not change wording or answer-line numbering. The
private originals remain separate; these files are not byte-for-byte transcript
copies.

Extra file-final blank padding outside the closing quotation fence is omitted.
Blank and decorative lines inside answers remain preserved. The source-item CSV
uses abbreviated labels and excludes decorative separators; see
[the index contract](../README.md#source-capture-limitations).
