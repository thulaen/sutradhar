# Reference

This page is for owners who need to look up a setting, an error or
what changed in a release. It helps you choose the right reference
in the manual for the exact version you verified.

## Settings

Use the settings reference to check a setting's purpose, default
and permitted values. Start with the current scope in the app.
Record the setting name and site or installation if you need to
compare it with the release's reference. See
[Configuration](configuration.md) for deciding whether to change it.

## Commands

The command reference is for advanced use. Use action help from the
same installed version to check the permission, expected result and
documented refusal codes. The desktop app is the normal route for
setup and recovery.

## Errors

Follow the local help link on the failing screen. Keep the error
message, its code, the step and your release version together.
If the app cannot start, use the recovery help from the verified
installer bundle. For what to share and what to keep private, see
[Troubleshooting](troubleshooting.md).

## Release notes

Use the notes for the exact release to check changes that affect
your site, data or PC. Read the update notice before accepting an
update. Follow [Operations](operations.md) for the backup and
rollback checks.

## If a reference is unavailable

> **Not yet available** applies where a release has not supplied
> the matching settings, commands, error reference or release notes.

These pages come from that release's own settings, action descriptions,
error catalogue and changelog. If an entry is missing, use the help
for the action you can verify in your release. Avoid applying a
default or instruction from a different version.
